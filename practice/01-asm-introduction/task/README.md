# Задача: Повторение на съобщението 7 пъти

## Условие

Допълнете и стартирайте кода в [rep7.asm](./rep7.asm), така че съобщението
„Repeat the message 7 times“ да се отпечата на екрана точно 7 пъти с помощта на
цикъл.

## Стъпки за компилация и стартиране

1. Асемблиране на кода:

   ```bash
   nasm -f elf64 rep7.asm -o rep7.o
   ```

2. Свързване с LD:

   ```bash
   ld rep7.o -o rep7
   ```

3. Стартиране на програмата:

   ```bash
   ./rep7
   ```

## Въпроси

След като програмата работи:

1. Защо `mov rax, 1` е вътре в цикъла, а не преди етикета `cycle`?

   <details>
   <summary>Отговор</summary>

   `syscall` връща резултата в `rax` - `write` връща броя записани байтове,
   27. Ако `mov rax, 1` е преди цикъла, второто извикване е системно извикване
   номер 27 (`mincore`) и съобщението се отпечатва само веднъж.

   </details>

2. Защо броячът е в `rbx`, а не в `rcx`? Опитайте.

   <details>
   <summary>Отговор</summary>

   `syscall` записва в `rcx` адреса за връщане (а в `r11` - `rflags`), така
   че стойността на брояча се губи при всяко извикване. `rcx` никога не става 7
   и цикълът е безкраен. Проверете в `gdb` с `p/x $rcx` преди и след `syscall`.

   </details>

3. Какво ще стане, ако замените `jnz` с `jz`?

   <details>
   <summary>Отговор</summary>

   След първото отпечатване `rbx = 1`, `cmp rbx, 7` дава `ZF = 0`, `jz` не
   прескача и програмата излиза от цикъла - съобщението се отпечатва веднъж.

   </details>

4. `print` е над `_start` във файла. Защо програмата започва от `_start`?

   <details>
   <summary>Отговор</summary>

   `ld` записва адреса на `_start` като входна точка на изпълнимия файл. Вижте
   го с `readelf -h rep7 | grep Entry` и го сравнете с `nm rep7`.

   </details>

## Допълнителни задачи

1. Вместо да броите знаците на ръка (`mov rdx, 27`), накарайте асемблера да
   пресметне дължината. *Подсказка:* `equ $ - message`.
2. Напишете `Makefile` с цели `rep7` и `clean`.
3. Пред всяко съобщение отпечатайте номера му: `1: Repeat the message 7 times`
   и т.н. *Подсказка:* в ASCII цифрата `n` е `'0' + n`.
4. Подайте на `print` броя повторения в регистър. Кой регистър можете да
   използвате и кой не?
